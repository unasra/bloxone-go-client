# Deprecated

This repository (`bloxone-go-client`) is deprecated and is no longer actively maintained.

Please migrate to the successor library:

**[universal-ddi-go-client](https://github.com/infobloxopen/universal-ddi-go-client)**

The new library provides the same BloxOne API coverage with improved design, ongoing updates, and continued support.

## Migration

Replace your import paths:

```go
// Before
import "github.com/infobloxopen/bloxone-go-client/..."

// After
import "github.com/infobloxopen/universal-ddi-go-client/..."
```

> **Note:** No further releases will be made to this repository.
